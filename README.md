# シャボン玉タスク

やることを「漂うシャボン玉」として表示する、個人用のタスク管理サイト。
締切の7日前から玉が膨らみはじめ、当日に最大、過ぎると薄い赤になる。
達成したら玉をタップ →「割る」でパチンと弾ける。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `style.css` | 見た目 |
| `script.js` | 動き・保存・効果音 |
| `apple-touch-icon.png` | ホーム画面に追加したときのアイコン |

外部ライブラリ・ビルドツールなし。データは端末の localStorage（キー `bubbleTask.v1`）に保存。

## GitHub Pages で公開する

1. GitHubで新しいリポジトリを作る（Public）
2. 上の4ファイルをリポジトリの直下にアップロード（Add file → Upload files）
3. Settings → Pages → Branch を `main` / `/(root)` にして Save
4. 数分後に表示される `https://<ユーザー名>.github.io/<リポジトリ名>/` を iPhone の Safari で開く
5. 共有ボタン →「ホーム画面に追加」

## 注意

- データはその端末・そのブラウザの中だけにある。Safari とホーム画面のアイコンではデータが別になるので、使う入口はどちらかに決める
- Safari の履歴・サイトデータを消去するとタスクも消える
- 数値の調整は `script.js` 冒頭の「設定値」でできる（最小・最大の大きさ、膨らみ始める日数、面積の上限など）
